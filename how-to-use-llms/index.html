第 1 章 · 基础

你正在和
一个 ZIP 文件对话

Karpathy 的心智模型：ChatGPT 是一个"单标签页 ZIP 文件"——一份对互联网的高度压缩快照。它读过截至训练截止日期之前几乎所有的网页、书籍和文档，那个截止日期通常在 6–12 个月前。它返回的是对那份数据的概率性回忆。

科学批注“几乎所有网页、书籍和文档”是夸张心智模型，不是事实描述；训练语料只覆盖可获取、可许可、可清洗的一部分文本。知识截止也不一定固定为 6–12 个月，取决于具体模型、产品和是否接入检索工具。

上下文窗口是它的工作记忆——一段它当前能看到的、容量有限的 token 磁带。在里面的内容可以直接访问；不在里面的内容对这次对话来说就不存在。会话之间默认没有持久记忆，除非你显式开启。

默认情况下它没有联网通道。模型只是在算"你的 prompt 接下来统计上最可能的延续"——这不是查询，不是搜索，也不是保证。

开场白 "你好，我是 ChatGPT。我是一个单标签页 ZIP 文件。我的知识来自大约 6 个月前对互联网的一次阅读。我只知道这次对话里出现的内容。我生成的每一个词都是一次概率采样——请相应对待。"

关于过期知识的提醒 对于像咖啡因含量这种"无时效"的事实，模型权重是可靠的。但对于上个月的新闻——它就靠不住。在相信答案之前，先想清楚是哪一类。

第 3 章 · 推理

思考型
模型

OpenAI 的 o1、o1 Pro、o3、o3-mini 是另一类——所有以 "o" 开头的模型都属于思考型模型。在给出回答前，它们会跑一段较长的内在独白：尝试不同思路、回溯、再试别的方案。

科学批注把推理模型说成“内在独白”容易误导。产品不会暴露完整链式思考；更稳妥的说法是：这类模型在回答前使用额外推理 token/计算预算，并经过强化学习优化复杂推理表现。

这是从强化学习中涌现出来的：模型发现"反复琢磨"的策略在难题上能拿到更好的结果。它会试想法、回退、复核推理——很像你解决问题时的内心独白。

Karpathy 提到，Claude 3.7 Sonnet（非思考型）解出了一道 o1 Pro 没能解出的高难度编码题。模型选择并不总是显而易见——选什么取决于具体任务。

什么时候该用思考型模型 硬核数学、复杂的多步代码、形式化推理、逻辑题。简单任务请跳过——它们更慢、更贵，而且当没有"难处"可以推理时，反复琢磨帮不了多少忙。

第 4 章 · 信息

什么时候
该搜索

默认情况下模型只跑在自己的权重上——没联网，也没实时数据。开启联网搜索意味着它先去取网页、再综合答案。这会带来延迟，但换来实时信息。

关键问题是：模型那份过期的回忆够不够用？ 对于文档充足、不带时效的知识——够。对任何时效性强、近期发生或冷门的话题——开搜索，或用 Perplexity。

  • ✕
    不用搜索："美式咖啡里有多少咖啡因？"——文档充足、没时效，模型都知道
  • ✕
    不用搜索："解释瑞利散射"——教科书物理，无需搜索
  • ✓
    开搜索："《白莲花度假村》第 3 季什么时候播出？"——时效性强，档期会变
  • ✓
    开搜索："现在去越南旅行安全吗？"——当前情况可能跟训练时不同
  • ✓
    开搜索："最近 USAID 削减是怎么回事？"——新闻，不在训练数据里
  • ✓
    开搜索："[某人] 用什么牙膏？"——冷门、可能近期、稀奇古怪

第 5 章 · 综合

深度
研究

深度研究（Deep Research） = 扩展思考 + 联网搜索，跑 5–15 分钟。模型并行检索几十个来源，跨来源做推理，再产出一份结构化报告——人类研究员往往要做几个小时。

Karpathy 的演示：研究雷帕霉素与长寿。模型查阅了 27 个以上的来源，思考了 5 分钟，产出一份覆盖作用机制（mTOR 抑制）、虫/鼠/人体试验数据、安全性顾虑、以及在研项目的报告。

ChatGPT Deep Research（需要 200 美元/月的 Pro 套餐）和 Perplexity 的研究模式都提供这个能力。对于文献综述、竞品分析、决策尽调——它把研究门槛大幅降低。

科学批注“必须 200 美元/月 Pro”已经容易过期。OpenAI 后续把 Deep Research 扩展到更多套餐并按额度区分；页面应标注这是讲座录制时的状态，而不是长期价格规则。
最适合用 科学文献综述、竞品格局分析、决策尽调、医疗/法律研究（需要复核）。简单事实问题不值得用。

第 6 章 · 阅读

文档与
书籍

把文档附加进去就把模型变成了一名阅读助手。上传一个 PDF、贴一段章节、共享一份表格——然后提问、要摘要、或者基于内容生成概念图。

Karpathy 的例子：用 Claude 读《国富论》。"我附上第 1 卷第 3 章——请基于此生成一张概念图。" Claude 用 Mermaid 代码 回应——这是一种图表标记语言，会被渲染成连接关键概念的关系图。

对于数据，模型可以写并执行 Python 来生成图表。但请把它当作 非常初级的数据分析师——写代码很出彩，但 Karpathy 抓到过它在图里幻造出 "1.7 万亿"这种数字。永远要审视具体数字，而不仅仅是图表的形状。

关键工作流 附加文档 → 要摘要 → 用问答深入到具体章节 → 让它出概念图（Mermaid）→ 对照原文核对任何具体数字。

第 7 章 · 数据分析

代码
执行

ChatGPT 的 高级数据分析（Advanced Data Analysis） 把模型接入了一个实时的 Python 运行环境。你用自然语言描述任务——它写代码、跑出来、把结果展示给你。无需复制粘贴，也无需本地搭环境。

这就是语言与计算的融合。算术、统计、数据清洗、生成图表——只要 Python 能做的事都能做。上传一份 CSV、要求分析趋势；几秒钟就能拿到一张 matplotlib 图。

Karpathy 的提醒：他抓到过模型在图里把正确数字幻造成了 "1.7 万亿"。代码跑得很正常，但数字是错的。把它当作能力很强但不可靠的初级——核实数字，而不只是输出的形状。

规则 当你需要计算、转换或可视化时使用代码执行。永远要检查：生成的代码是不是匹配你的要求？输出与你的源数据相比是否合理？

第 8 章 · 开发

智能体
编码

在对话之外，新一类工具把 LLM 直接集成进了代码编辑器。Cursor 与 Windsurf 在底层调用 Claude 或 GPT，能在你整个代码库范围内自主运作——读文件、写代码、运行命令、迭代。

Cursor 的 Composer（⌘I）是一个自主智能体循环：你描述任务，它就规划、写文件、跑 shell 命令、读取报错、再循环——任何破坏性操作前都会向你确认。Karpathy 用它几分钟从零搭出了一个 React 应用。

Karpathy 的设置中，底层模型是 Claude 3.7 Sonnet。关键洞察是：当你足够了解模型、能引导和纠正它的时候，这些工具才最强大；而不是只会发 prompt 然后听天由命。

第 9 章 · 多模态

语音与
音频

Karpathy 大约一半的查询走语音，使用 Super Whisper——他在 Super Whisper、WhisperFlow、MacWhisper 三者中的选择。按下热键、说话、再按一次——查询被转写并发出。无需打字，无障碍。

ChatGPT 的高级语音模式（Advanced Voice Mode）更进一步：音频 token 直接输入输出模型，没有中间的文字转写层。结果听起来真的像在对话，而不是 TTS 套壳。

科学批注这是对 GPT-4o 原生音频能力的合理概括，但产品实现会变：不同语音模式可能混合 ASR、语音到语音模型、TTS、安全分类器和工具层。不要把“没有中间转写层”当作所有语音产品的永久架构。

NotebookLM（Google）能把你的文档生成音频播客。上传论文、书籍或笔记——它会产出双主播讨论。Karpathy 在散步与长途驾驶时用它对自己专业之外的话题做被动学习。

Karpathy 的语音小贴士 当查询里包含产品名、库名或专有技术术语时——切到打字。Whisper 经常把冷门技术词转写错。语音最适合自然语言提问。

第 10 章 · 视觉输入

视觉与
摄像头

现代 LLM 接受图像输入——照片、截图、扫描件、图表。模型对视觉内容的推理与对文本的推理同样流畅，背后是包含数十亿"图像-文本"对的训练数据。

Karpathy 的例子：上传一张血液化验单请它解读、把摄像头对准 Aeronet 4 二氧化碳检测仪识别设备并解释 713 PPM 的读数、展示一张《魔戒》地图，它准确识别为中土世界。

视觉在文档充足的对象上最可靠——血液化验参考范围、常见消费电子产品、著名地图——这些训练数据覆盖密集。对于专有或稀有的物体，幻觉会更多。

视觉的强项用例 识别陌生物品、解读标准化验结果、解释图表与图示、在印刷文本上做 OCR、识别手写、分析截图。

第 11 章 · 个性化

记忆与
个性化

默认情况下，每段对话都是无状态的——标签页一关，模型就忘掉一切。两个特性会改变这一点：记忆（Memory）（ChatGPT 跨会话自动保存关于你的事实）与自定义指令（Custom Instructions）（一段持久的系统 prompt，影响每一条回答）。

Karpathy 的自定义指令：要求教学化的呈现方式（"尽可能讲得有教学性"），为学韩语设定礼貌正式的语体，分享他的工作背景与兴趣。

把自定义指令当作你的个人系统 prompt——每次对话开始前都会被加载。好的指令把你"每次都要重复一遍"的偏好压缩进去，让每段对话从一开始就显得"它认识你"。

入门用的自定义指令 "请简洁。能用代码就别用文字。我贴文档时，先给我一段话的摘要。把你做出的假设显式标出来。我的工作领域是 [你的领域]。"

第 13 章 · 总结

关键
要点

01
你正在和一个 ZIP 文件对话
模型把互联网压缩进了权重。知识大约过期 6–12 个月，输出是概率性的，上下文窗口外没有工作记忆。它无法核实自己的答案。
基础
02
了解你的套餐与模型
免费 → 受限。20 美元/月 → GPT-4o / Claude Sonnet。200 美元/月 → o1 Pro、深度研究。模型对应任务——硬推理用思考型、简单查询用快模型。科学批注套餐、模型名和额度是最高频变化项。这里应视为 2025 年讲座快照；到 2026 年，具体默认模型、订阅权益和价格必须查官方页面。
模型
03
只在时效性强时开搜索
对不带时效、文档充足的知识——权重已经够用，跳过搜索。对最近事件、变化中的情况、或冷门话题——开搜索或用 Perplexity。
搜索
04
用深度研究做多源综合
5–15 分钟、20–30 个来源、结构化报告。文献综述与决策尽调中确实有用。当前 ChatGPT 上需要 200 美元/月套餐；Perplexity 更便宜。科学批注同上，Deep Research 的可用套餐和额度已经变化；“当前需要 200 美元/月”不应保留为无日期断言。
研究
05
复核代码与数据输出
高级数据分析跑的是真的 Python——但模型可能在自己写的代码里幻造数值。请对照源数据核对数字，而不只是看图表的形状。
代码
06
语音消除一半的摩擦
基于 Whisper 的听写工具去掉了打字门槛。Karpathy 大约 50% 的查询走语音。当出现 Whisper 经常转写错的技术产品名、库名时改用打字。
语音
07
现阶段 ChatGPT 仍是默认
功能最多、生态最大、体验最完善。编码看 Claude，搜索优先看 Perplexity。格局变化很快——确定方案前去 LM Arena 看一眼当前排名。科学批注这是使用偏好，不是科学事实。更稳妥的建议是：按任务、数据敏感性、价格、延迟、上下文长度、工具能力和实测样例选择，而不是把某个产品设为永久默认。
生态
